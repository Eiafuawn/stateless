# Stateless 🏴🚩
Simple hugo theme with no visual bloat, no js, and an anar-comm color palette.

## Requirements
Hugo extended (SCSS support).

## Install
Add as a submodule:
```bash
git submodule add https://github.com/Eiafuawn/stateless themes/stateless
```
Then in your `config.toml`:
```toml
theme = 'stateless'
```
